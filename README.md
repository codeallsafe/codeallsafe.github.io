# İsa Cansın - Portfolio

Personal portfolio website showcasing my work as a Software Developer & Software Architect.

## About

This portfolio highlights my 6+ years of experience in full-stack development, cloud architecture, and microservices design. Built with Astro.js for optimal performance and modern web standards.

## Tech Stack

- **Framework:** Astro.js v5.1.5
- **Styling:** CSS
- **Deployment:** GitHub Pages

## Local Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev     # Runs at http://localhost:4321

# Build for production
npm run build

# Preview production build
npm run preview
```

## Deployment

This site is deployed on GitHub Pages. For deployment to other platforms, refer to the [Astro Official Deployment Guide](https://docs.astro.build/en/guides/deploy/).
